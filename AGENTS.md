# AGENTS.md — AUTONOMOUS ECONOMIC CORE™

## Governing intent
Build a lawful, policy-governed, evidence-terminated economic agent core that starts with zero new capital and proves real external net economic value.

## Canonical governance
All agent work follows:

`state → claim → evidence → next action`

Judgment vocabulary:
- `PASS` only when the required evidence exists.
- `HOLD` when external completion, evidence, configuration, or Human Threshold™ is pending.
- `BLOCKED` when a real constraint prevents safe progress.

Never upgrade a judgment because a task merely appears complete.

## Locked product truths
- First scientific target: `€0 → €0.01 VNEV`.
- Long-term headline metric: `Verified Banked Net Value™`.
- v0.1 requires zero new capital outlay.
- Identity is not authority.
- `SETTLED` is not `BANK_RECEIPT_VERIFIED`.
- `TASK_COMPLETED` is not `MONEY_EARNED`.
- Self-transfer, sandbox money, promo credit, fabricated counterparties, self-referral, or own-product self-purchase never count as external earned value.
- AEC™ is verified-learning, not uncontrolled self-modifying.

## Authority chain
`Intent → ENGÜRÜ Language Governance™ → Economic Principal → Delegated Authority → Policy → Economic Action → Evidence → DoneCheck™ → Human Threshold™ → Economic Finality`

## Human Threshold™
Stop and require human authority for:
- KYC,
- accepting new contracts/terms with legal effect,
- creating external financial accounts,
- changing payout destination,
- transferring/spending money beyond explicit narrow authority,
- irreversible legal declarations,
- ambiguous automation permission,
- material privacy/security risk.

## Engineering rules
1. Read current repository truth before changing it.
2. Preserve working verified behavior; apply only necessary differences.
3. Prefer Python standard library and SQLite in v0.1.
4. Do not add paid mandatory dependencies.
5. Do not store secrets in the repository.

9. Tests must cover positive, zero, negative, pending payout, anti-fake, and threshold boundary cases.
10. GitHub Actions is CI, not a 24/7 earning worker.
