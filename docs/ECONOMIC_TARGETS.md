# Economic Targets — Canonical Gates

AEC™ measures real economic progress through five evidence-backed thresholds.

## Gate 1 — Scientific Proof
**Target:** `€0 → €0.01 VERIFIED NET ECONOMIC VALUE (VNEV)`

Requirements:
- independent external counterparty,
- lawful/permitted task,
- accepted output,
- settled reward,
- reconciled amount,
- finalized direct costs,
- VNEV ≥ €0.01,
- complete evidence chain.

This gate proves that the economic loop can create real external net value.

## Gate 2 — Repeatability
**Target:** 10 separate real runs with positive VNEV.

No duplicate/self-generated economic events count. At least 10 independently evidenced run IDs are required.

## Gate 3 — Economic Engine Proof
**Target:** `≥ €0.10/hour net`

Hourly value is calculated from verified net economic value divided by measured active runtime attributable to the run set.

## Gate 4 — Utility
**Target:** `≥ €0.50/hour net`

This demonstrates practical economic usefulness under real operating conditions.

## Gate 5 — First Serious Target
**Target:** `≥ €1.00/hour VERIFIED NET ECONOMIC VALUE`

This is the first serious performance target; it is not assumed in advance.



## Locked Operating Focus — Sustainable $5/day VBNV

**Primary operating objective:** First produce **$5/day sustainable Verified Banked Net Value™**, then scale only the revenue line that has already produced verified banked value.

This operating objective does not replace The One Cent Test™. It sits above it:

`€0.01 VBNV proof → $1/day → $5/day sustainable VBNV → scale only verified line`

Rules:
- $5/day is a sustained operating target, not a guaranteed revenue claim.
- Scaling permission follows observed banked evidence, not worker count.
- 600 worker slots remain capacity only.
- A revenue line that has not produced verified banked value does not receive scale authority.
- Earned or settled value may be recorded daily while bank payout arrives later; VBNV is recognized only on verified bank/approved-account receipt and reconciliation.

## Banked truth
Long-term primary KPI:

**Verified Banked Net Value™ (VBNV)**

`Actual value verified as received in the designated payout/bank account − attributable direct costs = VBNV`

## Minimum payout exception
A platform may require a minimum payout threshold.

Example:
- Earned: €0.50 — PASS
- Settled: €0.50 — PASS
- Minimum payout: €10
- Bank payout: HOLD
- VBNV: €0.00

This is not failure. Economic value exists, but banked proof remains HOLD.

## The One Cent Test™ v2
Two distinct gates:

### A — One Cent Economic Test
`VNEV ≥ €0.01`

### B — One Cent Bank Test
`VBNV ≥ €0.01`

Possible truthful result:

`ONE_CENT_ECONOMIC_TEST = PASS`
`ONE_CENT_BANK_TEST = HOLD`

No later gate may be declared PASS without its own evidence.
